Laravel, Eloquent y API REST

Conceptos introductorios de ORM y ODM, operaciones CRUD, rutas dinámicas, verbos HTTP y contratos REST.

20 preguntasNivel básicoNota sugerida: 70%
Enfoque: comprender para qué sirve cada herramienta. Los ejemplos son deliberadamente pequeños y no requieren conocimientos avanzados de Laravel.

ORM

Relaciona objetos del programa con tablas de una base de datos relacional. Eloquent es el ORM de Laravel.

ODM

Relaciona objetos del programa con documentos de una base de datos documental, como MongoDB.

CRUD

Create, Read, Update y Delete: crear, consultar, actualizar y eliminar información.

API REST

Expone recursos mediante URLs y utiliza verbos HTTP como GET, POST, PUT y DELETE.

Ejemplo mínimo: guardar y exponer un producto

La idea importante es reconocer la ruta, el modelo, save() y la respuesta JSON.

Route::post('/api/products', function (Request $request) {
    $product = new Product();
    $product->name = $request->name;
    $product->save();

    return response()->json($product, 201);
});
