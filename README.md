# Examen de Desarrollo Web

Repositorio de estudio organizado por semanas. Cada evaluación combina las lecturas asignadas con el material presentado en clase.

## Contenido

- [Semana 6 - Arquitectura full stack y lenguajes del cliente/servidor](semana-06/index.html)

## Cómo usarlo

Abre `index.html` desde GitHub Pages o descarga el repositorio y abre el archivo en tu navegador. Cada examen permite responder, calcular la nota y revisar una explicación por pregunta.

## Fuentes de la Semana 6

- Material de clase: *Modern Full-Stack Architecture - Angular + ASP.NET Core*.
- Axarnet: lenguajes del lado del servidor.
- 1Library: lenguajes con soporte del servidor.
- Back4App: tecnologías del lado del cliente.

> Las evaluaciones son material de práctica académica y no sustituyen las indicaciones del docente.
